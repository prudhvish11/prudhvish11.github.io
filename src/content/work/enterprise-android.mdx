Production Android software running on a large, real-world device fleet — 15,000 and counting. The work sits where mobile, cloud, and operational reliability meet: it has to work the same way on device number one and device number fifteen thousand.

## Scale as the design constraint

At this size, the interesting problems aren't visual — they're structural. The software has to stay consistent across a fleet spread over many locations and network conditions, sync cleanly when connectivity drops and returns, and fail predictably rather than silently.

## Cloud ↔ device integration

The application layer talks to cloud services over REST, with synchronization designed around eventual consistency: devices reconcile state with the cloud without blocking on it. Retrieval workflows are cloud-integrated, so data reaching the device fleet stays current without manual redeployment.
